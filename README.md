# myGantt

간트 차트 기반 프로젝트 관리 웹앱입니다. https://gantt.dalhwa.com

## 기능

- **간트 차트**: 막대 드래그로 일정 이동, 양 끝을 드래그해 기간 조정, 하단 삼각형으로 진행률 조정. 날짜가 없는 작업은 행 위를 드래그해 일정을 그림
- **의존성**: 막대 끝의 점을 다른 막대로 드래그해 연결 (FS/SS/FF/SF, 지연일 설정 가능). 선행 작업이 늦어지면 후행 작업을 자동으로 미룸 (자동 일정 조정)
- **계층 구조**: 섹션, 하위 작업(여러 단계), 마일스톤. 상위 작업의 날짜와 진행률은 하위 작업에서 자동 계산
- **크리티컬 패스** 강조, **베이스라인** 저장·비교
- **줌**: 일 / 주 / 월 / 분기 / 년, 주말·휴일 음영, 오늘 표시선
- **여러 프로젝트**를 한 화면에 함께 표시, 프로젝트별 색상
- **보드(칸반)** 보기: 상태별 드래그 앤 드롭
- **워크로드** 보기: 팀원별 예상 시간 또는 작업 수, 용량 초과 표시
- **캘린더** 보기
- 작업 상세: 담당자(여러 명), 상태, 우선순위, 예상 시간, 색상, 설명, 체크리스트, 댓글, 링크
- 검색·필터 (담당자, 상태, 완료 숨기기, 내 작업)
- 실행 취소 / 다시 실행, 키보드 단축키 (Enter, Tab, Shift+Tab, Delete, ⌘D, ↑↓)
- 내보내기: PDF(여러 페이지·용지 선택), JPG, PNG, 인쇄, CSV(엑셀), JSON. 가져오기: CSV, JSON
- 근무일, 휴일 설정, 근무일 기준 기간 계산

데이터는 브라우저 localStorage에 저장됩니다 (서버 없음).

## 개발

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

`main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다 (`public/CNAME` = gantt.dalhwa.com).
